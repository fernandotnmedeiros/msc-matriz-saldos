# MSC · Matriz de Saldos Contábeis

Painel para conhecer a Matriz de Saldos Contábeis enviada ao Siconfi. Entes: Caruaru (PE).

Mostra como a base é organizada (classes do PCASP, tipos de valor, informações complementares), confere o equilíbrio da matriz e permite explorar cada conta.

Fonte: Siconfi / Tesouro Nacional, API de dados abertos (https://apidatalake.tesouro.gov.br/docs/siconfi/), endpoints msc_patrimonial, msc_orcamentaria e msc_controle.
